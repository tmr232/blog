      But Why?

      When coming to implement C++ semantics in Python, the first question we need to ask ourselves is "why?". The answer to that question is resource-management.

      Context Managers

      Context-managers are relatively straight-forward. To use them, we use the with statement.

      with open("file.txt") as f:
    data = f.read()
# f is closed automatically when the block exits.
